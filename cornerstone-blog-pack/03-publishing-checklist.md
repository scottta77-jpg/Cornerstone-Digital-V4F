# Technical checklist for Antigravity

Apply this checklist to all nine posts and the shared blog templates.

## 1. Remove leftover Olyyx brand mentions

Search case-insensitively for `Olyyx` in CMS globals, article bodies, footers, sidebars, shared components, metadata, structured data and image alt text. Replace leftover template branding with Cornerstone Digital where it identifies the business. Preserve any attribution required by the template licence. Search again after implementation and check the rendered pages.

## 2. Implement accurate Article / BlogPosting JSON-LD

Use each post's `schema` object in `schema-blueprints.json` as the starting point. Serialize it into a `<script type="application/ld+json">` element on that article's page, using the actual CMS values. Do not embed the outer blueprint array or its editorial instruction fields as structured data.

Include the headline, description, author, publisher, canonical page URL, publicly accessible image URL, `datePublished` and `dateModified`. Dates must be the actual publication and modification timestamps, including timezone. The visible page and markup must agree. Avoid conflicting duplicate Article schema generated by the CMS.

Use Cornerstone Digital as an `Organization` author and publisher unless a genuine named contributor is confirmed. Do not automatically attribute posts to Oliver Brown, Ethan Caldwell, Harrison Reed or Savannah Hayes merely because those names appear in the template.

Do not hard-code October 2026 as the publication date for every post. Do not add FAQPage schema to promise Google FAQ rich results; Google retired that feature from 7 May 2026. Visible FAQs can still help readers when relevant. Schema does not automatically guarantee indexing, rich results or selection by an AI search system.

Check the final JSON-LD using the relevant current validation tools, then inspect the published page source and indexing status separately.

## 3. Add one high-contrast yellow CTA block

Place one CTA block after the final article section and before related articles or the footer. This is the position after Final Thoughts if that heading is retained; the new articles use more specific closing headings.

Use the supplied `cta-block.html` as the component reference. Match the site's typography and spacing while retaining a yellow background, dark text, visible keyboard focus and a comfortable touch target.

- Button label: `BOOK YOUR 15-MINUTE DISCOVERY CALL →`
- Destination: `https://cornerstonedg.com/#booking`
- On article pages, use this full URL or `/#booking`, not just `#booking`, which would target the article itself.
- Do not substitute `#book-a-call`: the checked site uses `#booking`.
- Use the existing closing booking invitation as the copy for this block rather than adding repeated CTA paragraphs.

The Markdown files contain contextual booking links. Antigravity must turn the closing invitation into this shared styled component as part of implementation.

## 4. Verify the result

Check that all nine article routes, cards and the featured link work; confirm the CTA reaches the homepage calendar from an article page. Check desktop and mobile layouts, keyboard focus, source markup, actual publication dates, image delivery and related links. Verify contact delivery and analytics with appropriate test data.
