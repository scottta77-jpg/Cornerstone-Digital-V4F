# Cornerstone Digital blog publishing pack

Nine replacement articles, nine thumbnails and a researched editorial review. Prepared 21 October 2026. The live website has not been changed.

- `01-review-and-plan.md`: accuracy review, competitor resources, nine-slot replacement map and publishing checks.
- `02-all-articles.md`: review plus all nine complete posts and their metadata in one editable text file.
- `03-publishing-checklist.md`: explicit Olyyx cleanup, Article JSON-LD and yellow CTA implementation checks.
- `cta-block.html`: reusable high-contrast yellow booking button with styles.
- `posts/`: individual article files. Copy the article body into rich text, and map the metadata to CMS fields.
- `cms-content.json`: portable source data, not a claim of native compatibility with an uninspected CMS import format.
- `schema-blueprints.json`: per-post BlogPosting descriptions. Add actual publication dates, canonical and image URLs when publishing.
- `thumbnails/`: original PNG artwork and smaller WebP exports. Use WebP on the site; retain originals for future exports.
- `thumbnail-prompts.md`: the final prompt for every image.
- `Cornerstone-Digital-Blog-Review.html`: self-contained review and reading copy, including all artwork. Proposed article cross-links navigate within this copy; the individual content files retain the proposed site routes.

The dates in CMS data are intentionally empty because the posts are not yet published. Reading times use article text at 220 words per minute. All currency examples are labelled and no historical package prices have been treated as current Cornerstone offers. Article links use the observed `/blog/` route pattern and need working destinations before launch. Booking links use the site's current `/#booking` anchor.
